# crates/

The Rust workspace: `cc-ir` (IR types, op semantics), `cc-core` (config, artifacts, tool runners), `cc-pipeline`
(registry, DAG, scheduler), `cc-smt` (SMT-LIB and solver runner), `cc-passes` (one module per pass), `cc-cli`
(`chipc`). Documentation: [docs/framework/](../docs/framework/) and [docs/passes/](../docs/passes/).
